## CalculadoraIMC

### Descrição Geral
Este aplicativo foi desenvolvido como parte da disciplina de Programação Mobile, no 3º semestre do curso de Análise e Desenvolvimento de Sistemas da FECAP.

O objetivo do app é calcular o IMC (Índice de Massa Corporal) com base nas informações fornecidas pelo usuário e, a partir do resultado, apresentar uma mensagem positiva personalizada, juntamente com os dados de peso, altura, valor do IMC e sua classificação. A proposta busca valorizar o bem-estar e a saúde sem julgamentos, promovendo uma experiência leve, informativa e acolhedora.
